# Project continuity

- Before generating or changing character art, read `docs/art/characters.md` and inspect the relevant approved reference image.
- Use the approved character image as an image reference for each new pose, expression, outfit, or scene. A text prompt alone does not establish visual continuity.
- Preserve face structure, apparent adult age, eye color, hair color and hairstyle, body proportions, and identifying details unless the user explicitly approves a change.
- Treat new depictions as drafts until compared with the approved reference. Do not replace the canonical reference without explicit user approval.
- Dain and Xaden do not yet have approved visual identities. Their written style directions are not approved portraits.
- Keep concept screenshots and art documentation outside the published game bundle unless the user asks to integrate them.
- The author story map is local-only in ignored `tools-local/`; never add it to Git or the deployment bundle.
