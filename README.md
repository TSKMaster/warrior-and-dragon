# Воин и Дракон

Рабочее название романтической фэнтези-визуальной новеллы.

Первый этап — внутренний игровой прототип «Парапет»: диалоги, выборы, характеристики героини, отношения и финал с интригой.

## Сценарий

[Google Sheets — сценарий и карта ветвлений](https://docs.google.com/spreadsheets/d/1dDFC_991kI-gn5ZbczLMGK5Rrt_xqf7HvHZW3e0-d10/edit).

Снимок сценария находится в `story/pilot.json`: 8 сцен, 79 реплик, 6 точек выбора с 15 вариантами ответа и два финальных узла. При изменении сценария в таблице снимок обновляется отдельным коммитом; автоматическая синхронизация пока не настроена.

История — альтернативный сценарий внутреннего прототипа с персонажами «Четвёртого крыла». Развитие пилота не является пересказом канона.

## Запуск прототипа

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```sh
npm start
```

Откройте [игру в браузере](http://127.0.0.1:4173). Сервер доступен только на этом компьютере. Прямое открытие `index.html` двойным щелчком не поддерживается.

Прототип содержит весь пилот, условные варианты, характеристики, отношения, журнал, автоматическое сохранение и отдельный ручной слот. Сохранения хранятся в текущем браузере; очистка его данных удалит прогресс. «Продолжить историю» загружает автоматический слот, «Загрузить» — ручной. Новая игра заменяет автоматический слот.

Изображение академии и временные монограммы персонажей созданы для прототипа. Шрифты Google Fonts необязательны: без сети используются системные. Музыки и озвучки пока нет.

## Автоматическая публикация

Настройка GitHub Pages должна использовать источник GitHub Actions. Процесс `.github/workflows/pages.yml` запускается при отправке изменений в `main`: проверяет сценарий, собирает только игровые файлы в `dist/` и публикует их. Если проверки не проходят, текущая опубликованная версия сохраняется. Процесс можно запустить вручную из Actions.

Для локальной сборки: `npm run build`. Готовая папка `dist/` подходит для статического хостинга, в том числе в подпапке проекта. Изменения Google Sheets попадут на сайт после обновления `story/pilot.json` и отправки этого изменения в `main`.

## Проверка

```sh
npm test
```

Проверки перебирают все 194 допустимых маршрута, достижимость реплик, условия выбора, соответствие финалов спутнику и восстановление сохранений. Движок интерпретирует только ограниченный формат условий и присваиваний сценария, без выполнения произвольного кода.

## Работа с проектом

Авторская карта сценария доступна только в локальной рабочей папке. Каталог `tools-local/` исключён из Git и сборки GitHub Pages; в опубликованной игре нет ссылки на карту. Файлы самого сценария используются браузерной игрой и остаются публичными.

На авторском компьютере карта запускается командой `node tools-local/story-map/server.mjs` и открывается по адресу `http://127.0.0.1:4175`. Это просмотр текущего `story/pilot.json`: сцены, решения, последствия, поиск, диалоги и условия переходов. После изменения файла нажмите «Обновить сценарий». Редактирование и сохранение сценария через карту пока не реализованы.

Код, сценарные снимки и исходные материалы храним в этом репозитории. Завершённые изменения сопровождаем понятным коммитом и отправляем на GitHub. Временные выгрузки и зависимости исключены из истории.

Браузерный прототип находится в корне проекта; сценарий хранится отдельно от интерфейса в `story/pilot.json`.
